⌨️ PC Keyboard Shortcuts

Master keyboard controls for desktop play:

← / → Step backward / forward through match moves
↑ / ↓ Jump to match start / return to live position
Z or U Undo last move
H Request tactical advice / hint
F Flip board orientation (White ↔ Black)
Esc Close dialog / return to match
1 2 3 Switch Tabs (1: Home, 2: Tactics, 3: Profile)
F11 Toggle fullscreen mode
Mouse Click-to-move OR Drag-and-drop pieces
